## 📖 Project Overview

**Sema Code Extension** is an intelligent programming plugin built on the [Sema Code Core](https://github.com/midea-ai/sema-code-core) engine, available as both a VSCode extension and a JetBrains plugin (IntelliJ IDEA / PyCharm / GoLand / WebStorm / CLion, etc.).

## ✨ Key Features

- **Natural Language Instructions** - Drive programming tasks directly with natural language
- **Permission Control** - Fine-grained permission management keeps every operation safe and controllable
- **Subagent Management** - Multi-agent collaboration, dynamically dispatching the right subagent for each task type
- **Skill Extension** - A pluggable architecture for flexibly extending AI coding capabilities
- **Plan Mode** - Break down complex tasks and plan their execution
- **MCP Support** - Built-in Model Context Protocol support for tool extension
- **Multi-Model Support** - Compatible with Anthropic and OpenAI SDKs, supporting mainstream LLM APIs worldwide
- **Multilingual UI** - Available in 中文 / English / Deutsch / Français / Italiano

## 🚀 Installation

### VSCode

1. Open Visual Studio Code
2. Go to the Extensions view (`Ctrl+Shift+X`)
3. Search for `Sema Code` and click Install
4. Or download the VSIX from [GitHub Releases](https://github.com/midea-ai/sema-code-vscode-extension/releases) and install it manually

### JetBrains (IntelliJ IDEA / PyCharm / GoLand / WebStorm / CLion, etc.)

1. Open your JetBrains IDE
2. Go to `Settings → Plugins`
3. Search for `Sema Code` and click Install
4. Or download the plugin package from [GitHub Releases](https://github.com/midea-ai/sema-code-vscode-extension/releases) and install it manually
